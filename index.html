// 04 · Araç Seti

Kodlama Bir Araç, Nihai Amaç Değil

Kodlamayı fazla kafaya takma. C öğrenmenin asıl amacı; performans, cache (önbellekleme) ve makinenin nasıl düşündüğünü anlamak. Senin için kodlama Python ve R arasında dönecek.

Python

  • 3. seviye güçlü programlama dili

  • Pandas, PyTorch, NumPy kütüphaneleri var
  • Veri Bilimi, Makine öğrenmesi, Website yapımı, Masaüstü uygulama yapımı gibi alanlarda kullanılır.
  • Anlamadığın kodlar için Yapay Zekaya sor

§ 05 — Veritabanı
// SQL

SQL — Yapılandırılmış Sorgu Dili

  • 4. seviye kodlama dili
  • Verilerin saklandığı Database ile konuşmayı sağlar
  • Okunaklı sözdizimi: CREATE, DELETE, UPDATE...
  • Veri bilimci olarak SQL bilgin şart
  • Veri barındırma, çekme, optimizasyon, anlamlı sonuç çıkarma
SELECT JOIN CREATE DELETE UPDATE
// NoSQL

NoSQL — Duymamış Olabilirsin

  • Verilerle konuşma ve depolamaya yarar
  • Ama SQL dili kullanmaz
  • Tablo, sütun, satır yok — farklı formatlar
  • SQL'e göre daha esnek ama daha az düzenli
  • Veriler JSON gibi formatlarda saklanır
→ NOT SQL'i iyi öğren, NoSQL'e sonra geçersin.
§ 06 — Veri & Araçlar
// Veri Formatları

Birkaç Önemli Husus

CSV
Virgül ile ayrılmış değerler. Datacı olarak en çok kullanacağın dosya türü. Veri taşımada standart format.
JSON
NoSQL ve web'de yaygın. ~1 saatlik öğrenme süresi. Araştır, öğren, geç.
XML
Eski ama kullanılan format. 1 saatlik öğrenme. Ara sıra karşına çıkar, korkma.
